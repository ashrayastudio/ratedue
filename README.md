# RateDue website

Static website for [ratedue.com](https://ratedue.com), hosted with GitHub Pages.

The site has no runtime dependencies, backend, analytics, or tracking. Edit the HTML/CSS directly and serve the repository root locally to preview changes.

## Pages

- `/` — product overview
- `/privacy/` — privacy policy
- `/support/` — support and common questions
- `/terms/` — terms of use
